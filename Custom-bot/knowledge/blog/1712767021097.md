## [**如何在线调试开发？**](https://anwen-anyi.github.io/index/build/kaifa.html#%E5%A6%82%E4%BD%95%E5%9C%A8%E7%BA%BF%E8%B0%83%E8%AF%95%E5%BC%80%E5%8F%91)

### [**1.1 调试前准备**](https://anwen-anyi.github.io/index/build/kaifa.html#_1-1-%E8%B0%83%E8%AF%95%E5%89%8D%E5%87%86%E5%A4%87)

我们先下载一个编译好的AList，然后将AList前端代码([**alist-webopen in new window**](https://github.com/alist-org/alist-web))下载到本地

- 下载已经可以直接使用的AList，然后启动
- 下载AList前端代码：**git clone --recurse-submodules** [**https://github.com/alist-org/alist-web.gitopen in new window**](https://github.com/alist-org/alist-web.git)

  - 仔细看有 `--recurse-submodules` 参数，如果不加会缺少`solid-router`运行的时候会报错

### [**1.2 加载包管理器所需要的安装项目依赖**](https://anwen-anyi.github.io/index/build/kaifa.html#_1-2-%E5%8A%A0%E8%BD%BD%E5%8C%85%E7%AE%A1%E7%90%86%E5%99%A8%E6%89%80%E9%9C%80%E8%A6%81%E7%9A%84%E5%AE%89%E8%A3%85%E9%A1%B9%E7%9B%AE%E4%BE%9D%E8%B5%96)

我们这里在线调试使用的开发工具是 **VS Code** (Visual\_Studio\_Code) ，如果你使用 **WebStorm**JetBrains 也可以

进入调试工具打开前端的代码，执行如下代码

```
pnpm install
```

然后就会加载`package.json`这里面提到的我们需要的项目依赖，会在同级目录的`node_modules`暂时存储

(第一次加载可能会慢一些，如果你后续继续开发的话`node_modules`留着不要删除后续继续用)

#### [**1.2.1 后续继续开发调试**](https://anwen-anyi.github.io/index/build/kaifa.html#_1-2-1-%E5%90%8E%E7%BB%AD%E7%BB%A7%E7%BB%AD%E5%BC%80%E5%8F%91%E8%B0%83%E8%AF%95)

我们后续继续开发调试的时候，AList版本也会更新依赖也会更新，到时候我们继续使用`pnpm install`安装命令来更新就好

之要之前使用的`node_modules`文件夹没有删除后续更新基本几秒钟的时间

### [**1.3 修改调试配置**](https://anwen-anyi.github.io/index/build/kaifa.html#_1-3-%E4%BF%AE%E6%94%B9%E8%B0%83%E8%AF%95%E9%85%8D%E7%BD%AE)

- 进入开发调试工具后我们先修改两个文件

  - 如果你需要在局域网其他电脑查看效果需要修改两个文件
  - 如果你只是在本地这台电脑修改不需要要修改
- 两个文件都需要修改，缺一不可

**文件1文件2**

文件1：alist-web/`package.json`

我们这里在线调试用 `dev` 启动我们就修改`dev`即可

#### [**修改前**](https://anwen-anyi.github.io/index/build/kaifa.html#%E4%BF%AE%E6%94%B9%E5%89%8D)

```
......
    "start": "vite",
    "dev": "vite",
    "build": "vite build",
......
```

```
> alist-web@0.0.0 dev alist-web
> vite

  VITE v3.0.8  ready in 952 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

#### [**修改后**](https://anwen-anyi.github.io/index/build/kaifa.html#%E4%BF%AE%E6%94%B9%E5%90%8E)

```
......    
    "start": "vite",
    "dev": "vite --host 0.0.0.0",
    "build": "vite build",
......
```

```
> alist-web@0.0.0 dev alist-web
> vite --host 0.0.0.0

  VITE v3.0.8  ready in 1994 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.137.1:5173/
  ➜  Network: http://192.168.140.1:5173/
  ➜  Network: http://192.168.200.1:5173/
  ➜  Network: http://192.168.31.14:5173/
```

这样修改的好处就是 启动 Vite 构建工具时并指示它在本地主机的所有 IP 地址上监听请求，方便我们在其他设备也能预览

像开始那样如果我们不添加参数,只能使用`http://localhost:5173/`然后用本机访问，无法使用局域网内或者其他设备预览查看
