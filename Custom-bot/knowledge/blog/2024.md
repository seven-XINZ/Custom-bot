## 三、安装傻妞机器人

```bash
s=sillyGirl;a=arm64;if [[ $(uname -a | grep "x86_64") != "" ]];then a=amd64;fi ;if [ ! -d $s ];then mkdir $s;fi ;cd $s;wget https://github.com/cdle/${s}/releases/download/main/${s}_linux_$a -O $s && chmod 777 $s;pkill -9 $s;$(pwd)/$s
```

等待宝塔安装pm2管理器完成后输入命令测试安装成功

## 四、检查安装是否成功（显示版本则安装成功）

```
node -v

```

## 五、设置管理员

```bash
s=/etc/sillyGirl;if [ ! -d $s ];then mkdir $s; fi; echo "set qq masters 你的管理QQ号" > /etc/sillyGirl/sets.conf
```

## 六、安装QQ机器人

```
#安装oicq
cd && git clone https://github.com/takayama-lily/oicq.git
#运行oicq
oicq QQ账号
#pm2挂oicq
pm2 start "oicq QQ号"
#升级oicp
npm up -g oicq

#安装onebot
cd && git clone https://ghproxy.com/https://github.com/takayama-lily/node-onebot.git

#安装go-cqhttp
#创建储存go-cqhttp文件
cd && mkdir -p qqbot && cd /root/qqbot
#拉取go-cqhttp
wget https://github.com/Mrs4s/go-cqhttp/releases/download/v1.0.1/go-cqhttp_linux_amd64.tar.gz
#解压
tar -zxvf go-cqhttp_linux_amd64.tar.gz
#删除
rm go-cqhttp_linux_amd64.tar.gz
#启动go-cqhttp
./go-cqhttp
```

## 七、修改onebot的config.yml文件

root文件夹找到node-onebot文件夹点击进入,找到config.sample.js,右键把把config.sample.js重命名config.js然后修改

```
platform: 5,//1:安卓手机 2:aPad 3:安卓手表 4:MacOS 5:iPad
access_token: "123456",//访问api的token
ws_reverse_url: ["ws://127.0.0.1:8080/qq/receive"],//反向ws地址，可以添加多个url
```

## 七、1.修改go-cqhttp的config.yml文件

启动完成后这里选3，ctrl+c结束进程
然后去/root/qqbot/下修改config.yml

```
# go-cqhttp 默认配置文件
# 访问密钥, 强烈推荐在公网的服务器设置
access-token: '傻妞QQ密钥'
# 注意 设置了此项地址后下面两项将会被忽略
universal: ws://127.0.0.1:8080/qq/receive
```

发送命令检测是否pm2可用

```
pm2 list
#安装命令
npm install pm2 -g

# 运行node-onebot
cd && cd node-onebot && node main QQ账号

# 重新运行go-cqhttp
./go-cqhttp

#回车，扫码登录，回车。如果输入密码提示账号被冻结请使用扫码
```

修改完成输入ssh命令(遇见ws反向失败可删除账号重新输入下面命令即可登陆然后通过命令挂起qq)

```bash
cd && cd sillyGirl && ./sillyGirl -t
./sillyGirl -d

#安装过screen可跳过（可不安装）
yum -y install screen
screen -ls#查看会话
screen -S qqbot#创建会话
screen -r qqbot#恢复会话
screen -S xxxx.qqbot -X quit#删除会话

# pm2挂机运行node-onebot
cd && cd node-onebot && node main QQ账号
ctrl+c
pm2 start "node main 机器人QQ号"

# 静默运行go-cqhttp
cd /root/qqbot && ./go-cqhttp -d
#pm2挂机
pm2 start "./go-cqhttp"

#结束QQ机器人
ps -ef#确定要杀死进程的 PID 或 PPID
kill -KILL 123456
pm2 list#查看进程
pm2 delete 0
```

## 八、管理员qq给机器人qq发

```
set jd_cookie enable_jd_cookie true
```

然后发 重启

## 九、打开文件（找不到 就安装宝塔搜索文件 config.yaml）

```
/usr/local/sillyGirl/conf/config.yaml
```

把你的redis信息填写进去保存

```
enable_redis: true
redis_addr: 127.0.0.1:7000
redis_password:
```

然后保存 发送 重启 指令
发 name 如果出现回复 安装成功
